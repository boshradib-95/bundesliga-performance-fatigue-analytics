# Bundesliga Performance & Fatigue Analytics (2025-2026)

A professional sports analytics dashboard evaluating player workload, physical fatigue distribution through a custom thematic visual, and attacking efficiency in the German Bundesliga.

## 📊 Project Overview
This project explores physical workload, fatigue percentages, and attacking contributions of Bundesliga players for the 2025-2026 season. It bridges sports science and data visualization to give a comprehensive view of player performance.

## 🛠️ Tools & Technologies
- **Python:** Data cleaning, processing, and exploratory data analysis.
- **SQL:** Querying and structuring dataset metrics.
- **Tableau Public:** Designing and publishing the interactive dashboard.

## 📁 Dataset Description
The analysis relies on comprehensive player performance data covering Europe's top 5 leagues for the 2025-2026 season:
- `players_data-2025_2026.csv`: Full dataset containing 102 detailed performance metrics.
- `players_data_light-2025_2026.csv`: Streamlined dataset containing 53 core statistical attributes.
